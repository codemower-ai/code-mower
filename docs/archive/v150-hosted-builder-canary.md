# v1.5.0 Hosted-Builder Completion Canary

This note exists only as a release-qualification canary for the hosted builder
lifecycle. The pull request that introduces it is intentionally left unmerged
so maintainers can verify, end to end, that a hosted builder can receive a
trusted work order, write a single branch, open exactly one pull request
against the intended base, and return a structured completion for the exact
pushed head.

- It grants no merge or publication authority.
- It contains no private task or account data.
- It must not be treated as product documentation.

See [`../v150-qualification.md`](../v150-qualification.md) for the current
qualification checklist this canary supports.
